# Operators

Every operator has a forward kernel, a gradient (a backward kernel or a composition of operators),
and a double-precision host reference. The order of implementation follows the operator plan:
waves ranked by how many of 11 reference models use each operator, with operators that need new
TornadoVM features last.

## Wave 1 (done)

| Operator | Kernels (`jitnn-core/.../kernels`) | Gradient |
|---|---|---|
| add, sub, mul, div, maximum, minimum, comparisons, with broadcasting | `ElementwiseKernels.binary`, `binaryBroadcast` | sum over broadcast axes |
| neg, exp, log, sqrt, abs, relu, pow, clamp, reciprocal, square, affine | `ElementwiseKernels.unary` | element-wise rules |
| sum, mean, max, min along an axis; full sums | `ReduceKernels.reduceGroup`, `reduceThread`, `reduceRowsSplit`, `reduceColumnsSplit` | broadcast back; extremum mask |
| argmax | `ReduceKernels.argmaxThread` | none |
| reshape | a view, no kernel | reshape back |
| permute, transpose | `ElementwiseKernels.permute`, `transposeTiled32` | inverse permutation |
| matmul with either transpose | `GemmKernels.gemm`, `gemm64`, `gemm128`, `gemmSimdgroup` | two GEMMs |
| linear (+ bias, + ReLU, fused) | the GEMMs with an epilogue, `biasActivation` on Metal | GEMMs, ReLU mask, bias sum |
| softmax, log-softmax (last axis) | `SoftmaxKernels.softmaxRowsCached`, `softmaxRows` | `softmaxBackwardRows` |
| cross-entropy (fused, mean) | `crossEntropyRows` + mean | `crossEntropyBackwardRows` |
| NLL | `nllRows` | `nllBackward` |
| uniform, normal (Philox4x32-10) | `RandomKernels.philox` | none |
| SGD, SGD momentum and Nesterov, Adam, AdamW | `OptimKernels` | none |

## Wave 2 (operators and gates done; performance work open)

| Operator | Kernels | Gradient |
|---|---|---|
| Conv2D: square kernel, symmetric stride, padding, dilation; groups; fused bias and ReLU | `ConvKernels.conv2dForward` (implicit GEMM, 64x64 register blocks, generated by `scripts/codegen/conv_gemm.py`) | `conv2dBackwardData` (implicit GEMM gathering dy), `conv2dBackwardWeight` (split-K), bias by reduction |
| Depthwise Conv2D (groups = channels) | `ConvKernels.depthwiseForward` (direct) | `depthwiseBackwardData`, `depthwiseBackwardWeight` (split) |
| BatchNorm (NCHW or NC), training and inference, running statistics, fused ReLU | `NormKernels.batchStats`, `batchApply`, `batchApplyRunning` | `batchBackwardReduce`, `batchBackwardApply` |
| Max pooling, average pooling (padding counted) | `PoolKernels.maxForward` (records argmax), `avgForward` | `maxBackward`, `avgBackward` (gathers, no atomics) |
| Global average pooling | reduction over H x W | broadcast back |
| Dropout (inverted, per-step seed, mask regenerated in backward) | `RandomKernels.dropout` | the same kernel on dy |
| ReLU6 | clamp | clamp mask |
| LR schedules: step, multi-step, cosine | host | |

Modules: `Conv2d`, `BatchNorm2d`, `MaxPool2d`, `AvgPool2d`, `GlobalAvgPool2d`, `Flatten`, `Dropout`,
`ReLU6`, `Add` (residual). Models in `nn.models`: `ResNet.resnet18` and `MobileNetV2.mobilenetV2`
(torchvision layouts, plus a small-input variant).

## Wave 3 (done)

| Operator | Kernels | Gradient |
|---|---|---|
| tanh, sigmoid, GELU (erf and tanh forms), SiLU; SwiGLU = silu(gate) * up | `ElementwiseKernels.unary` (own overflow-free tanh and an erfc approximation) | fused codes in `binary` (`TANH_GRAD`, `GELU_GRAD`, ...) |
| narrow, slice, split, chunk, cat, stack, unsqueeze, squeeze | `copyBlock` (one copy per part), `fill` | narrow of the gradient; zero-fill plus copy back |
| Embedding, with a padding index | `gatherRows` | deterministic segment sum `segmentSumRows` over indices grouped on the host (no atomics) |
| LayerNorm, RMSNorm over the last axis | `NormKernels.rowNormForward` (one work-group per row) | `rowNormBackward`, parameter gradients by `rowNormParamPartials` + `sumPartials` (deterministic) |
| Batched matmul: equal batch dimensions, or one shared matrix | `GemmKernels.gemm64Batched` (generated, batch folded into the grid's y) | batched products; a shared matrix's gradient summed over the batch |
| Scaled dot-product attention: causal (PyTorch's top-left alignment) and additive masks; multi-head self-attention | batched GEMMs + `SoftmaxKernels.attentionSoftmaxRows` (scale and causal limit fused) | `attentionSoftmaxBackwardRows` and the GEMM gradients |
| Rotary position embedding, rotate-half and interleaved, with a position offset | `ElementwiseKernels.rope` (cos/sin tables computed in double, cached on the device) | the same kernel rotating backwards |
| Gradient clipping by global norm | composed, lazily on the device | |
| Warm-up with linear or cosine decay | host | |
| Top-k (values and indices), multinomial sampling | `SampleKernels.topkRows`, `multinomialRows` (Philox) | top-k: `topkBackward` |
| FP16 and BF16 tensors; casts (round to nearest even) | `LowPrecision.f32ToF16`, `f16ToF32`, `f32ToBF16`, `bf16ToF32` (BF16 as raw bits) | cast back to the input's type |
| Half-precision GEMMs (FP16 or BF16 operands, FP32 accumulation and result), plain, batched and fused linear | `GemmKernels.gemm64F16`, `gemm64BF16`, `gemm64BatchedF16`, `gemm64BatchedBF16` (generated) | the products in the half type |
| Autocast | casts at `F.linear`, `matmul` and attention | |
| Dynamic loss scaling | `LowPrecision.anyNonFinite` (bit-pattern test) and a skip gate in the optimiser kernels | |

`F.linear` now takes inputs with any leading dimensions. Modules: `Embedding`, `LayerNorm`,
`RMSNorm`, `MultiheadAttention`. Models in `nn.models`: `GPT2`, `Llama` (Llama-style decoder) and
`Bert` (masked language modelling).
