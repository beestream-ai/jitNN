# Operators

Every operator has a forward kernel, a gradient (a backward kernel or a composition of operators),
and a double-precision host reference. The order of implementation follows the operator plan:
waves ranked by how many of 11 reference models use each operator, with operators that need new
TornadoVM features last.

## Wave 1 (done)

| Operator | Kernels (`jitnn-core/.../kernels`) | Gradient |
|---|---|---|
| add, sub, mul, div, maximum, minimum, comparisons, with broadcasting | `ElementwiseKernels.binary`, `binaryBroadcast` | sum over broadcast axes |
| neg, exp, log, sqrt, abs, relu, pow, clamp, reciprocal, square, affine | `ElementwiseKernels.unary` | element-wise rules |
| sum, mean, max, min along an axis; full sums | `ReduceKernels.reduceGroup`, `reduceThread`, `reduceRowsSplit`, `reduceColumnsSplit` | broadcast back; extremum mask |
| argmax | `ReduceKernels.argmaxThread` | none |
| reshape | a view, no kernel | reshape back |
| permute, transpose | `ElementwiseKernels.permute`, `transposeTiled32` | inverse permutation |
| matmul with either transpose | `GemmKernels.gemm`, `gemm64`, `gemm128`, `gemmSimdgroup` | two GEMMs |
| linear (+ bias, + ReLU, fused) | the GEMMs with an epilogue, `biasActivation` on Metal | GEMMs, ReLU mask, bias sum |
| softmax, log-softmax (last axis) | `SoftmaxKernels.softmaxRowsCached`, `softmaxRows` | `softmaxBackwardRows` |
| cross-entropy (fused, mean) | `crossEntropyRows` + mean | `crossEntropyBackwardRows` |
| NLL | `nllRows` | `nllBackward` |
| uniform, normal (Philox4x32-10) | `RandomKernels.philox` | none |
| SGD, SGD momentum and Nesterov, Adam, AdamW | `MultiTensorKernels` (4 parameters per launch, generated) | none |

## Wave 2 (operators and gates done; performance work open)

| Operator | Kernels | Gradient |
|---|---|---|
| Conv2D: square kernel, symmetric stride, padding, dilation; groups; fused bias and ReLU | `ConvKernels.conv2dForward` (implicit GEMM, 64x64 register blocks, generated by `scripts/codegen/conv_gemm.py`) | `conv2dBackwardData` (implicit GEMM gathering dy), `conv2dBackwardWeight` (split-K), bias by reduction |
| Depthwise Conv2D (groups = channels) | `ConvKernels.depthwiseForward` (direct) | `depthwiseBackwardData`, `depthwiseBackwardWeight` (split) |
| BatchNorm (NCHW or NC), training and inference, running statistics, fused ReLU | `NormKernels.batchStats`, `batchApply`, `batchApplyRunning` | `batchBackwardReduce`, `batchBackwardApply` |
| Max pooling, average pooling (padding counted) | `PoolKernels.maxForward` (records argmax), `avgForward` | `maxBackward`, `avgBackward` (gathers, no atomics) |
| Global average pooling | reduction over H x W | broadcast back |
| Dropout (inverted, per-step seed, mask regenerated in backward) | `RandomKernels.dropout` | the same kernel on dy |
| ReLU6 | clamp | clamp mask |
| LR schedules: step, multi-step, cosine | host | |

Modules: `Conv2d`, `BatchNorm2d`, `MaxPool2d`, `AvgPool2d`, `GlobalAvgPool2d`, `Flatten`, `Dropout`,
`ReLU6`, `Add` (residual). Models in `nn.models`: `ResNet.resnet18` and `MobileNetV2.mobilenetV2`
(torchvision layouts, plus a small-input variant).

## Wave 3 (done)

| Operator | Kernels | Gradient |
|---|---|---|
| tanh, sigmoid, GELU (erf and tanh forms), SiLU; SwiGLU = silu(gate) * up | `ElementwiseKernels.unary` (own overflow-free tanh and an erfc approximation) | fused codes in `binary` (`TANH_GRAD`, `GELU_GRAD`, ...) |
| narrow, slice, split, chunk, cat, stack, unsqueeze, squeeze | `copyBlock` (one copy per part), `fill` | narrow of the gradient; zero-fill plus copy back |
| Embedding, with a padding index | `gatherRows` | deterministic segment sum `segmentSumRows` over indices grouped on the host (no atomics) |
| LayerNorm, RMSNorm over the last axis | `NormKernels.rowNormForward` (one work-group per row) | `rowNormBackward`, parameter gradients by `rowNormParamPartials` + `sumPartials` (deterministic) |
| Batched matmul: equal batch dimensions, or one shared matrix | `GemmKernels.gemm64Batched` (generated, batch folded into the grid's y) | batched products; a shared matrix's gradient summed over the batch |
| Scaled dot-product attention: causal (PyTorch's top-left alignment) and additive masks; multi-head self-attention | batched GEMMs + `SoftmaxKernels.attentionSoftmaxRows` (scale and causal limit fused) | `attentionSoftmaxBackwardRows` and the GEMM gradients |
| Rotary position embedding, rotate-half and interleaved, with a position offset | `ElementwiseKernels.rope` (cos/sin tables computed in double, cached on the device) | the same kernel rotating backwards |
| Gradient clipping by global norm | `GradStats`, applied inside the optimiser update | |
| Warm-up with linear or cosine decay | host | |
| Top-k (values and indices), multinomial sampling | `SampleKernels.topkRows`, `multinomialRows` (Philox) | top-k: `topkBackward` |
| FP16 and BF16 tensors; casts (round to nearest even) | `LowPrecision.f32ToF16`, `f16ToF32`, `f32ToBF16`, `bf16ToF32` (BF16 as raw bits) | cast back to the input's type |
| Half-precision GEMMs (FP16 or BF16 operands, FP32 accumulation and result), plain, batched and fused linear | `GemmKernels.gemm64F16`, `gemm64BF16`, `gemm64BatchedF16`, `gemm64BatchedBF16` (generated) | the products in the half type |
| Autocast | casts at `F.linear`, `matmul` and attention | |
| Gradient statistics for clipping and loss scaling: global norm, unscale-and-clip factor, overflow flag | `LowPrecision.sumSquaresFinite` (one per gradient, bit-pattern test) and `gradStats`; the optimiser kernels apply the factor and skip on overflow | |

`F.linear` now takes inputs with any leading dimensions. Modules: `Embedding`, `LayerNorm`,
`RMSNorm`, `MultiheadAttention`. Models in `nn.models`: `GPT2`, `Llama` (Llama-style decoder) and
`Bert` (masked language modelling).

## Wave 4 (done on CUDA and OpenCL; Metal not run yet)

| Operator | Kernels | Gradient |
|---|---|---|
| LeakyReLU, softplus | `ElementwiseKernels.unary` (softplus through `log1p`, Goldberg's trick: TornadoMath has none) | `LEAKY_RELU_GRAD`, `SOFTPLUS_GRAD` |
| MSE; binary cross-entropy on probabilities (logs clamped at -100, as PyTorch) and on logits; Gaussian KL | `binary` codes `BCE`, `BCE_LOGITS`; MSE and KL composed | `BCE_DX`, `BCE_DY`, `BCE_LOGITS_DX`: finite at p = 0 and 1 |
| Transposed 2-D convolution: stride, padding, output padding, dilation, groups, bias | the convolution kernels: forward is `conv2dBackwardData` of the matching convolution | data gradient by `conv2dForward`, weight gradient by `conv2dBackwardWeight` |
| Nearest and bilinear upsampling (align_corners either way), by scale or to a size | `ResizeKernels.forward` | `ResizeKernels.backward`, one thread per input pixel gathering the outputs that read it (deterministic) |
| LSTM and GRU layers (PyTorch's equations and gate order), any number of layers, initial states | input projection for the whole sequence as one GEMM, then `RnnKernels.lstmForward`/`gruForward`, one kernel per timestep | `lstmBackward`/`gruBackward` per timestep in reverse, dW_hh as one GEMM over the sequence |
| Random fills seeded from a tensor | `RandomKernels.philoxSeeded` | |

`Tensor.uniform`/`normal` take the seed as an INT32 [2] tensor (`Tensor.seed(long)`), so noise drawn
every step (VAE sampling, GAN latents) replays the compiled step instead of recompiling it. Modules:
`ConvTranspose2d`, `Upsample`, `LeakyReLU`, `Sigmoid`, `Tanh`, `LSTM`, `GRU`. Models in
`nn.models`: `Vae`, `Dcgan.Generator`/`Dcgan.Discriminator`, `UNet` and `CharRnn` (an LSTM or GRU
language model). The final cell state of an LSTM carries no gradient.

## Wave 5 (operators done on CUDA and OpenCL; Metal not run yet)

| Family | Operators | Kernels | Gradient |
|---|---|---|---|
| Activations | ELU, SELU, CELU, Mish, Softsign, HardSigmoid, HardSwish, HardTanh, ThresholdedReLU, Cube, PReLU (shared or per-channel slope), RReLU | `ElementwiseKernels` codes (expm1 by Kahan's trick: TornadoMath has none); RReLU's slopes from Philox | fused gradient codes; PReLU's slope gradient by reduction |
| Math and logic | sin, cos, tan, asin, acos, atan, sinh, cosh, asinh, acosh, atanh, erf, erfc, round (half to even), trunc, floor, ceil, sign, log1p, expm1, atan2; ne, le, logical and/or/xor/not; where; one-hot | element-wise codes; `where` and one-hot kernels | composed from the element-wise ops; comparisons and logic have none |
| Losses | L1, Huber, smooth L1, NLL, hinge, squared hinge, cosine similarity and cosine proximity, Poisson NLL, MSLE, MAPE | composed | autograd |
| Optimisers | AdaGrad, RMSProp (momentum, centred), AdaDelta, AdaMax, NAdam, AMSGrad; Nesterov already in SGD | `MultiTensorKernels` (generated, 3 or 4 tensors per launch) | |
| Norms | GroupNorm, InstanceNorm, local response normalisation, weight normalisation | the row-norm kernel; `NormKernels.lrnForward` | `lrnBackward` (gathering); composed |
| Spatial | Conv1D and Conv3D (groups 1), 1-D and 3-D max/avg pooling, adaptive avg/max pooling (1 to 3 axes), constant/reflect/replicate padding | `SpatialKernels`: N-D unfold (im2col) + the batched GEMM, adaptive pooling, padding | `fold`, adaptive and padding gradients, all gathering per input (deterministic) |
| Scans and sorting | cumsum, cumprod, sort, argsort (stable) | `ScanKernels`: a scan per line; sort by rank | reverse cumsum; cumprod's exact with zeros; through the ranks |
| Indexing | index_select, gather, scatter, scatter_add, segment sum/mean/max, EmbeddingBag | `IndexKernels` | gathering (no atomics); scatter (replace) has none |
| INT8 | Q8_0 tensors (GGUF's 32-value blocks), quantise, dequantise, Q8_0 linear | jitllm's: `Q8Kernels` (adapted), `NativeProjectionKernels.dequantizeQ8_0ToFP32`; warp product on CUDA and Metal, shared-memory tree elsewhere | to the input, through the dequantised weight |
| Sequences | masked (lengths) and bidirectional LSTM and GRU layers, per-sequence reversal | `RnnKernels` with lengths | masked steps pass none |
| Images | flip, centre crop, normalisation, RGB to greyscale | composed | autograd |
| NaN-aware | isNaN, isInf, isFinite, nanToNum, maximum/minimum propagating NaN, fmax/fmin ignoring it | bit-pattern tests (TornadoVM folds `x != x`, J19) | where defined |

Modules: `ELU`, `SELU`, `CELU`, `Mish`, `Softsign`, `Softplus`, `HardSigmoid`, `HardSwish`,
`HardTanh`, `ThresholdedReLU`, `Cube`, `PReLU`, `RReLU`, `GroupNorm`, `InstanceNorm`,
`LocalResponseNorm`, `Conv1d`, `Conv3d`, `MaxPool1d`, `AvgPool1d`, `MaxPool3d`, `AvgPool3d`,
`AdaptiveAvgPool`, `AdaptiveMaxPool`, `Pad`, `EmbeddingBag`; `LSTM` and `GRU` gain
`bidirectional` and sequence lengths. Optimisers in `nn.optim`: `AdaGrad`, `RMSProp`, `AdaDelta`,
`AdaMax`, `NAdam`, and `Adam` with `amsgrad`. Not done: Conv1D/3D with groups, NaN-propagating
reductions.
